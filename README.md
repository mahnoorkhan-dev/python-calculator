# Python Basic Calculator
# Features & Basic Functions

The calculator supports four core mathematical operations:
* Addition (+): Adds two numbers together.
* Subtraction (-): Finds the difference between two numbers.
* Multiplication (*): Multiplies two numbers.
* Division (/): Divides the first number by the second (includes built-in error handling for division by zero).
# Execution Time & Performance

Performance is tracked using Python's high-precision `time.perf_counter()` module. 

* Average Execution Time: `< 0.01 milliseconds` for all basic arithmetic operations.
* Efficiency: Because operations are implemented using native Python data types and direct functions, computational overhead is minimal ($O(1)$ time complexity).

# How to Run
1. Ensure you have **Python 3.x** installed on your system.
